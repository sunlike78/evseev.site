# ScreenCreep

## Проект
Браузерная мета-кликер игра с визуальной эволюцией. Игра начинается как примитивный кликер в углу экрана и постепенно «захватывает» весь браузер — ломает интерфейс, вылезает за границы, визуально эволюционирует от пикселей к сложным формам.

## Цели
- Монетизация через рекламу (AdSense, rewarded video, interstitial)
- Вирусный эффект через мета-механики (игра ломает четвёртую стену)
- MVP за 1-2 недели с помощью AI-assisted разработки

## Стек
- HTML5 / CSS3 / JavaScript (vanilla или минимальный фреймворк)
- Canvas API для визуальных эффектов
- Без бэкенда на старте (localStorage для сохранений)

## Монетизация
- Interstitial реклама между этапами эволюции
- Rewarded video за бонусы/ускорение
- Баннерная реклама на странице

## Правила разработки
- Код на английском, комментарии на русском при необходимости
- Простота > сложность. YAGNI.
- Каждая фича — отдельный коммит с понятным сообщением
- Тестировать в Chrome (основной браузер)
