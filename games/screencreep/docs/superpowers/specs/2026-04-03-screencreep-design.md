# ScreenCreep — Design Specification

## Overview

**ScreenCreep** — браузерная мета-кликер игра с визуальной эволюцией. Игра начинается как примитивный кликер в углу экрана и постепенно «захватывает» весь браузер — ломает интерфейс, вылезает за границы, визуально эволюционирует от пикселей к сложным формам.

**Целевая аудитория:** Казуальные игроки, любители idle/clicker игр, пользователи, ищущие необычный браузерный опыт.

**Уникальное торговое предложение (USP):** Игра ломает четвёртую стену, «захватывая» браузер игрока. Каждый этап эволюции — сюрприз, который игрок не ожидает.

**Бизнес-цель:** Монетизация через рекламу (AdSense, rewarded video, interstitial). Proof of concept для модели «AI-assisted разработка → доход».

---

## 1. Основная механика

Игра делится на 5 этапов эволюции (stages). Каждый этап — новый визуальный и геймплейный слой:

| Этап | Название | Что видит игрок | Механика |
|------|----------|----------------|----------|
| 1 | Зарождение (Seed) | Маленький пиксельный квадрат в углу страницы | Простой клик = +1 очко |
| 2 | Рост (Growth) | Квадрат растёт, появляются цвета | Автокликеры, первые апгрейды |
| 3 | Прорыв (Breach) | Игра «ломает» свою рамку, вылезает за границы div | Новые типы ресурсов (глитчи) |
| 4 | Захват (Takeover) | Элементы страницы «заражаются» — меняются цвета, шрифты, фон | Мета-механики: клик по элементам страницы |
| 5 | Доминация (Domination) | Весь экран — это игра, UI полностью трансформирован | Финальная прогрессия, prestige-система |

**Ключевая killer-фишка:** игрок не знает, что будет на следующем этапе. Каждый переход — сюрприз и вау-момент.

---

## 2. Система прогрессии и апгрейдов

### 2.1 Ресурсы

- **Пиксели (pixels)** — основная валюта. Зарабатываются кликами и автокликерами.
- **Глитчи (glitches)** — вторая валюта, появляется на этапе 3+. Зарабатываются, когда игра «ломает» новый элемент интерфейса. Нужны для мета-апгрейдов.
- **Коды (codes)** — prestige-валюта. Получаются при prestige-сбросе на этапе 5.

### 2.2 Дерево апгрейдов

**Базовые (за пиксели):**
- Автокликер — пассивный доход пикселей
- Множитель клика — x2, x5, x10...
- Скорость автокликера — клики/сек

**Мета-апгрейды (за глитчи):**
- «Расширение территории» — игра захватывает больше экрана
- «Визуальная мутация» — новые визуальные эффекты, частицы, анимации
- «Заражение UI» — меняет конкретные элементы страницы (кнопки, текст, фон)

**Prestige-система (этап 5):**
Игрок может «сбросить» прогресс и начать заново, получив «коды» — перманентные бонусы. Каждый prestige-цикл — новый визуальный скин эволюции. Создаёт бесконечную реиграбельность.

### 2.3 Кривая прогрессии

| Этап | Время достижения | Ключевое событие |
|------|------------------|------------------|
| 1 → 2 | ~5 мин | Появление автокликера |
| 2 → 3 | ~15 мин | Первые визуальные мутации |
| 3 (Прорыв) | ~20-30 мин | **ВАУ-момент:** игра ломает свою рамку |
| 3 → 4 | ~30-60 мин | Глитчи, мета-апгрейды |
| 4 → 5 | ~1-2 часа | Полный захват экрана |
| Prestige | ~3-4 часа | Сброс и перерождение |

Первый «вау» (прорыв рамки) — через ~20-30 минут. Достаточно рано, чтобы не потерять игрока, но достаточно поздно, чтобы он почувствовал прогресс.

## 3. Монетизация и реклама

### 3.1 Точки вставки рекламы

| Момент | Тип рекламы | Обоснование |
|--------|-------------|-------------|
| Переход между этапами (1→2, 2→3...) | Interstitial (полноэкранная) | Естественная пауза, игрок ждёт «что дальше» |
| Игрок застрял / хочет ускорение | Rewarded video | «Посмотри рекламу = x2 пикселей на 10 мин» |
| Prestige-сброс | Interstitial | Загрузка «нового мира» — логичная пауза |
| Постоянно на странице | Баннер | Только на этапах 1-2. На этапе 3+ игра «пожирает» баннер (вау-момент) |

### 3.2 Rewarded video — основной доход

Варианты наград за просмотр:
- x2 автоклик на 10 минут
- Ускорение перехода к следующему этапу
- Бесплатный глитч — одно мета-улучшение
- Визуальный бонус — временные спецэффекты (частицы, свечение)

**Принцип:** rewarded video всегда опционально. Игрок никогда не обязан смотреть рекламу для прогресса.

### 3.3 Фишка: реклама как часть геймплея

На этапе 4 («Захват»), когда игра «заражает» UI — она визуально «поглощает» рекламный баннер. Игрок видит, как пиксели переползают на рекламу и «съедают» её. Это создаёт вау-эффект и убирает баннер естественно.

### 3.4 Рекламная платформа

Google AdSense для баннеров + Google Ad Manager для interstitial/rewarded video.

### 3.5 Ожидаемые метрики (консервативно)

| Метрика | Значение |
|---------|----------|
| ARPU (доход на пользователя) | $0.05 — $0.15 |
| Средняя сессия | 15-30 мин |
| Rewarded video за сессию | 2-3 просмотра |
| Interstitial за сессию | 1-2 показа |

## 4. Технический стек и архитектура

### 4.1 Стек

| Слой | Технология | Обоснование |
|------|-----------|-------------|
| Рендеринг | Canvas 2D API | Достаточно для пиксельной графики и эффектов, проще WebGL |
| Логика | Vanilla JS (ES6+) | Без фреймворков — меньше зависимостей, быстрее загрузка |
| Стили | CSS3 | Для мета-эффектов (анимация DOM-элементов, трансформации UI) |
| Сохранение | localStorage | Без бэкенда, всё на клиенте |
| Сборка | Vite | Быстрый dev-сервер, минификация для продакшна |
| Хостинг | GitHub Pages или Cloudflare Pages | Бесплатно, CDN из коробки |
| Реклама | Google AdSense + Ad Manager | Единая экосистема |

### 4.2 Архитектура модулей

```
src/
├── main.js              # Точка входа, инициализация
├── game/
│   ├── GameLoop.js       # requestAnimationFrame, update/render цикл
│   ├── ClickHandler.js   # Обработка кликов, множители
│   ├── Resources.js      # Пиксели, глитчи, их подсчёт
│   ├── Upgrades.js       # Дерево апгрейдов, покупка
│   └── Prestige.js       # Логика prestige-сброса
├── stages/
│   ├── StageManager.js   # Переключение этапов, условия перехода
│   ├── Stage1_Seed.js    # Зарождение
│   ├── Stage2_Growth.js  # Рост
│   ├── Stage3_Breach.js  # Прорыв рамки
│   ├── Stage4_Takeover.js# Захват UI
│   └── Stage5_Domain.js  # Доминация
├── meta/
│   ├── DOMInfector.js    # «Заражение» элементов страницы
│   ├── FrameBreaker.js   # Выход за границы контейнера
│   └── VisualEffects.js  # Частицы, свечение, глитч-эффекты
├── ads/
│   ├── AdManager.js      # Управление показами рекламы
│   └── RewardedVideo.js  # Rewarded video логика
├── save/
│   └── SaveManager.js    # localStorage: save/load/export
└── utils/
    └── BigNumber.js      # Большие числа для поздней игры
```

### 4.3 Ключевые технические решения

**Мета-эффекты (главная фишка):**
- Этап 3: JS динамически меняет CSS `overflow: hidden` → `visible` на контейнере игры, canvas «вылезает» за div
- Этап 4: `DOMInfector.js` находит элементы страницы и применяет CSS-анимации (transform, filter, color), постепенно меняя их стиль
- Этап 5: overlay на `position: fixed` поверх всего viewport

**Производительность:**
- Canvas рендерит только изменённые области (dirty rectangles)
- Idle-расчёты при возврате: `offlinePixels = rate × secondsAway`
- Автосохранение каждые 30 секунд

**Размер:**
- Цель: < 500KB загрузка (без рекламных скриптов)
- Никаких тяжёлых библиотек

## 5. MVP Scope

Для первого релиза (1-2 недели):

**Включено:**
- Этапы 1-3 (до прорыва рамки включительно)
- Базовые апгрейды (автокликер, множитель)
- Пиксели как единственный ресурс
- localStorage сохранение
- Баннерная реклама (AdSense)
- Хостинг на GitHub Pages / Cloudflare Pages

**Отложено до v2:**
- Этапы 4-5 (захват и доминация)
- Глитчи и мета-апгрейды
- Prestige-система
- Rewarded video и interstitial
- Звуки и музыка
- Мобильная адаптация
