### Click Texts (~300-500 per language)

Stored separately in `src/data/texts-{locale}.js` (see click-texts spec). These are NOT translations of each other — each language has its own culturally native humor pool.

## Architecture

### File Structure

```
src/i18n/
├── i18n.js           — Core: locale detection, t() function, interpolation
├── locales/
│   ├── en.js         — English UI strings
│   ├── ru.js         — Russian UI strings
│   └── de.js         — German UI strings
src/data/
├── texts-en.js       — English click texts (300+ strings)
├── texts-ru.js       — Russian click texts (300+ strings)
└── texts-de.js       — German click texts (300+ strings)
```

### i18n.js API

```js
// Initialize with auto-detected or saved locale
export function initI18n(savedLocale = null) {
  const locale = savedLocale
    || detectBrowserLocale()  // navigator.language → 'en'|'ru'|'de'
    || 'en';                  // fallback
  loadLocale(locale);
  return { t, setLocale, getLocale };
}

// Translation function with interpolation
export function t(key, params = {}) {
  // 'spore.lucky' + { n: 500 } → 'LUCKY! +500 px'
  let str = strings[key] || fallback_en[key] || key;
  for (const [k, v] of Object.entries(params)) {
    str = str.replace(`{${k}}`, v);
  }
  return str;
}

// Switch locale at runtime
export function setLocale(locale) {
  loadLocale(locale);
  // triggers UI re-render
}

// Detect from browser
function detectBrowserLocale() {
  const lang = navigator.language.slice(0, 2);
  if (['en', 'ru', 'de'].includes(lang)) return lang;
  return null;
}
```

### Locale Files Format

```js
// src/i18n/locales/en.js
export default {
  'stage.seed': 'Seed',
  'stage.growth': 'Growth',
  // ... all keys from table above
};
```

Flat key-value. No nesting. Simple `string.replace` for interpolation (`{n}`, `{name}`).

### Fallback Chain

1. Current locale string
2. English string (always complete)
3. Raw key (developer debug — should never show in production)

## Integration

### How Code Changes

**Before:**
```js
toast.show('First Growth');
```

**After:**
```js
toast.show(t('milestone.cellGrow'));
```

### Files That Need Changes

| File | Change |
|------|--------|
| `main.js` | Import `t()`, replace all hardcoded milestone/stage strings |
| `UIPanel.js` | Replace upgrade labels, stage names, lock text |
| `Upgrades.js` | Move `label` and `description` to locale files, use keys |
| `Stage1_Seed.js` | Replace "click the cell" with `t('hint.click_cell')` |
| `GoldenSpore.js` | Replace frenzy/lucky messages with `t()` calls |
| `FloatingNumbers.js` | No change (numbers are universal) |
| `AchievementToast.js` | No change (receives already-translated strings) |
| `ClickTexts.js` | Loads `texts-{locale}.js` at init, swaps on locale change |

### Language Switcher UI

Small flag/label in top-left corner (next to mute button):

```
[EN] [RU] [DE]
```

- Compact text buttons, not flag icons (flags are politically loaded)
- Active locale highlighted
- Click switches instantly, saves to localStorage
- ClickTexts pool reloads on switch

### Save/Load

- `localStorage.screenCreep_locale` stores current locale
- Loaded at init before any rendering
- Default: browser auto-detect

## Click Text Cultural Adaptation

These are NOT translations. Each language gets its own native humor:

### Russian Humor Style
- Сарказм и самоирония: "Ну и зачем ты это делаешь?" / "Клетка тоже устала"
- Мягкий мат-стайл: "Ёклмн, сколько клеток" / "Ну ты даёшь, блин"
- Ру-нет мемы: "Нельзя просто так взять и..." / "Совпадение? Не думаю"
- Экзистенциальный юмор: "Смысл? Какой смысл?" / "И это вся жизнь"
- Программерские шутки на русском: "Баг или фича?" / "Это не баг, это организм"

### German Humor Style
- Ordnung und Bürokratie: "Zellwachstum genehmigt. Formular B-12." / "Bitte nehmen Sie eine Nummer"
- Compound word comedy: "Zellvermehrungsbeschleunigungsknopf" / "Klickverarbeitungseinheit"
- Dry wit: "Interessant." / "Das war... ein Klick."
- Denglisch mix: "Very nice Biomasse" / "Das ist ja mega-organisch"
- Self-aware precision: "Exakt 47 Zellen. Nicht 46. Nicht 48."

### English Humor Style
- Internet culture: programming jokes, meme references, self-aware meta
- (Already detailed in click-texts spec)

## Performance

- Locale files are small (~5KB each for UI strings)
- Click text files larger (~15-20KB each, 300+ strings) — loaded lazily on first click
- `t()` is a simple object lookup + string replace — negligible cost
- No runtime parsing, no ICU library, no pluralization engine (not needed for this game's strings)

## Future Extensions

- More languages added by creating new locale file + click text file
- Community translations possible — just add a new `.js` file
- Mutation names (Session DNA) will also need i18n keys when implemented
